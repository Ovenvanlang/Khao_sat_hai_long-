Kiến trúc ba lớp đơn giản: giao diện web, backend API và CSDL. Backend chia thành bốn khối: middleware truy cập, Survey Service (UC1, UC2, UC8), Report Service (UC3 → UC6) và Sentiment Module (UC7, COULD).
